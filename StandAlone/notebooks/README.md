# Notebook Layout

These notebooks implement the study structure from [`../docs/roadmap/design3.md`](../docs/roadmap/design3.md).

They are organized by foundation topic rather than by week, because the mixed phase structure in `design3.md` is better for planning than for repeated hands-on practice.

## Order

1. `00_foundation_index.ipynb`
2. `01_python_foundations.ipynb`
3. `02_python_internals_and_performance.ipynb`
4. `03_software_engineering_foundations.ipynb`
5. `04_dsa_problem_solving_foundations.ipynb`
6. `05_sql_database_foundations.ipynb`
7. `06_systems_linux_networking_foundations.ipynb`
8. `07_data_platform_foundations.ipynb`
9. `08_systems_design_foundations.ipynb`
10. `09_trading_data_ml_foundations.ipynb`

## Intent

- `01` builds Python language fluency.
- `02` deepens Python internals, runtime, and performance reasoning.
- `03` turns that into engineering discipline.
- `04-05` build structural reasoning in DSA and databases.
- `06-08` build systems, platform reliability, and systems design reasoning.
- `09` bridges into the trading AI/ML vertical.

Each notebook contains:

- topic map
- drill bank
- build milestones or artifact targets
- exit criteria
- starter code or scratch cells
