# StandAlone Learning Workspace

This folder is organized as a small study and portfolio workspace for the `design3` roadmap.

## Structure

- `docs/roadmap/`: current roadmap and active planning documents
- `docs/archive/`: superseded designs kept for reference
- `notebooks/`: topic-based study notebooks
- `projects/`: implementation projects and portfolio artifacts
- `tests/`: shared or cross-project verification if needed
- `data/sample/`: tiny mock datasets that are safe to commit
- `data/generated/`: generated outputs that should usually stay out of git
- `progress/`: progress tracking and weekly notes

## Start Here

1. Read [`docs/roadmap/design3.md`](docs/roadmap/design3.md).
2. Open [`notebooks/00_foundation_index.ipynb`](notebooks/00_foundation_index.ipynb).
3. Start with the Python and software engineering notebooks.
4. Promote anything substantial into `projects/`.
